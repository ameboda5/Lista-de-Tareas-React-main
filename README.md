# APP LISTA DE TAREAS

Este proyecto tiene como proposito mostrar una aplicacion funcional sobre tareas para prueba tecnica de informa Colombia .

## Descripción

aplicacion de tareas todo-app

## Características

- aplicacion echa con react 
- funcionalidad get , update y delete
- uso de apis 

## Instalación

Sigue estos pasos para instalar el proyecto:

```bash
# Clona el repositorio
git clone https://github.com/ameboda5/Lista-de-Tareas-React-main

# Entra en la carpeta del proyecto
cd LISTA-DE-TAREAS-REACT

# Instala las dependencias
npm install

#abrir navegador con la url normalmente es : 
http://localhost:3000/
